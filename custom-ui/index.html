    Справка по стратегиям

    Бот «Стратегии» может одновременно использовать несколько включённых алгоритмов. Сделка откроется по сигналу любой из них, в пределах общего лимита позиций.

    Grid (отдельный бот)

    VolatilityGridStrategy — торговля в боковике при достаточной волатильности (Bollinger Bands + ADX). Усреднение позиции сеткой (~1.2% против движения), частичный TP у середины BB. Стоп-лосс и ROI — как у остальных ботов (−8%, ROI 3%→0%).

    FreqAI (отдельный бот)

    FreqaiExampleStrategy + LightGBM — прогноз направления цены моделью машинного обучения. Работает независимо от стратегий ниже; настройка только через конфиг FreqAI.

    Стратегии бота «Торговля стратегиями»

      Настройки

      Стратегии бота

      Включите одну или несколько. Бот откроет сделку по сигналу любой активной стратегии. Общий лимит одновременных сделок не меняется.

        Одновременные сделки

        Лимит для каждого бота отдельно. Изменение сохраняется в config и применяется через reload.

        Торговые пары

        Добавление пар вручную — только для FreqAI. Grid и Стратегии подбирают пары сканером.

        Активные пары

          В чёрном списке (не торгуются)
