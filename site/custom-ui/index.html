                    Инструкция CriptoTools

                    Как пользоваться панелью: вход, ключи Bybit, боты, стратегии, сделки, статистика и дашборд. Описания алгоритмов — в кнопке «Инфо».

                    Старт Вход Ключи Боты Стратегии Сделки Аналитика Меню Админ

                    Быстрый старт

                    1. Войдите в панель.
                    2. Если это обычный аккаунт — в Настройках сохраните API Key и Secret Bybit.
                    3. Включите нужные стратегии и проверьте лимиты (число позиций и stake).
                    4. На карточке «Стратегии + ML gate» нажмите Старт.
                    5. Следите за открытыми сделками на главной; итоги смотрите в Статистике, Дашборде и Истории.

                    Клик по иконке или названию CriptoTools в шапке всегда возвращает на главную панель.

                    1. Вход

                    1. Откройте панель по HTTPS (порт 8443).
                    2. Введите логин и пароль → «Войти».
                    3. Сессия хранится до 7 дней, пока не нажмёте «Выйти».

                    Admin — владелец сервера (общие боты и ключи с сервера). User — свой логин, свои ключи Bybit и свои изолированные боты.

                    2. Ключи Bybit

                    Нужны обычному пользователю. Без ключей боты не запустятся (жёлтый баннер сверху).

                    1. В Bybit создайте API Key с правом торговли USDT Perpetual / фьючерсами (не только Read).
                    2. Панель → Настройки → Секреты биржи.
                    3. Вставьте Key и Secret → «Сохранить ключи».
                    4. Подождите несколько секунд — боты перезапустятся, баннер исчезнет.

                    Ключи шифруются на сервере и обратно не показываются. У admin отдельная форма не нужна — ключи уже на сервере.

                    3. Четыре бота на главной

                    • ML Finder — сканер рынка по ML-модели TradeFinder + фильтр входа. Часто выключен на admin; у user работает со своими ключами, если включён.
                    • Стратегии + ML gate — основной бот. Несколько алгоритмов одновременно; сделка открывается по сигналу любой включённой стратегии, но только если ML gate пропускает вход.
                    • Grid + ML — внутренний grid CryptoTools (волатильность / боковик) с ML-фильтром.
                    • Bybit Grid — нативная сетка прямо на бирже Bybit. Создаётся с панели. ML gate не использует. Лимит активных сеток — в настройках.

                    На карточке бота: статус, баланс и PnL, Старт / Стоп, открытые сделки, кнопка «Статистика» по этому боту.

                    4. Стратегии и лимиты

                    1. Откройте Настройки (или блок стратегий на карточке бота).
                    2. Включите нужные алгоритмы. Хотя бы одна должна быть активна, иначе сигналов не будет.
                    3. Переключатель «SL/TP из обучения» — стоп и тейк из сценария обучения. Если выключен — используются глобальные SL/TP из настроек риска.
                    4. Лимиты ботов: «макс. сделок» — сколько позиций одновременно; «на одну стратегию» — потолок открытых сделок с одним enter_tag (0 = без лимита); stake — размер одной сделки в USDT. Значение 0 у «макс. сделок» останавливает бота — он не торгует, пока не поставите 1 или больше.
                    5. У нового user по умолчанию 1 слот на Finder / Strategy / Grid и 1 Bybit Grid. Можно поднять (до 50 позиций / до 5 Bybit Grid), как у admin.

                    ML gate на стратегиях: режим profit_only, порог уверенности от ~45% (у каждой стратегии может быть свой). Grid и Finder — свои пороги. Bybit Grid без ML.

                    5. Сделки

                    • Открытые позиции — в карточке бота: пара, сторона, PnL, данные ML.
                    • «Закрыть» — выход по рынку. Если на бирже позиции уже нет, панель предложит списать её в историю.
                    • Не гоняйте несколько ботов на одной паре без нужды — они не видят чужие позиции и могут конфликтовать.
                    • Следите за свободной маржой на Bybit: при нехватке USDT новые входы отклоняются биржей.

                    6. Статистика, дашборд, история

                    • Статистика — таблица по стратегиям/ботам: прибыль, убыток, число успешных и неуспешных сделок. Период: сегодня, вчера, неделя, месяц, всё время.
                    • Дашборд — две диаграммы: доля стратегий в доходе и в расходе (в %). Фильтры по боту и периоду. Наведение на сектор или строку легенды подсвечивает стратегию.
                    • История — все закрытые сделки с фильтрами (бот, стратегия, период, пары) и экспортом CSV.
                    • Логи — поток логов в реальном времени (если нужно разобраться, почему бот не входит или остановился).

                    7. Меню панели

                    • CriptoTools (иконка / название) — на главную.
                    • Статистика — сводная таблица PnL.
                    • Дашборд — диаграммы долей стратегий.
                    • История — журнал сделок.
                    • Инфо — описание стратегий и ML.
                    • Инструкция — этот текст.
                    • Изменения — журнал смены настроек.
                    • Логи — диагностика.
                    • Настройки — ключи, лимиты, стратегии, пары.
                    • Обновить — принудительно обновить данные панелей.

                    8. Только для admin

                    1. Настройки → Пользователи — создать логин и пароль нового user.
                    2. User входит сам, указывает свои ключи Bybit и получает свой контур ботов.
                    3. Можно отключить аккаунт или сбросить пароль.
                    4. Admin продолжает торговать на общем стеке сервера (strategy / grid / finder).

                    Не передавайте пароль admin и серверные секреты пользователям — у каждого свой изолированный контур.

                    Справка по стратегиям

                    Бот «Стратегии» использует включённые алгоритмы и ML gate (XGBoost): сделка откроется только при прогнозе profit с уверенностью ≥60%. Сигнал — от любой активной стратегии, в пределах лимита позиций.

                    ML gate (прод, июл 2026)

                    Модель pnl_classifier (XGBoost + isotonic) обучена на sim trade_db (~5900 сделок). Режим profit_only ≥60% — все боты CriptoTools (ML Finder, Стратегии, Grid). Сканер Finder дополнительно требует ≥52% на своей модели. Bybit Grid ML не использует.

                    Bybit Grid (нативный, 4-й бот)

                    Futures Grid на бирже Bybit — сетка ордеров в заданном диапазоне цен. Режимы: Neutral (лонг ниже / шорт выше), Long, Short. Арифметическая или геометрическая сетка, TP/SL, trailing. Управляется через API Bybit, не через ботов CriptoTools.

                    Grid-бот (отдельный процесс)

                    VolatilityGridStrategy — боковик при волатильности (Bollinger + ADX). Частичный TP у середины BB, cooldown после SL. На входе — ML gate (сценарий live_grid).

                    ML Finder (отдельный бот)

                    TradeFinderStrategy + XGBoost — сканер рынка по OHLCV-фичам, long/short. ATR stop/TP, cooldown. Второй фильтр — pnl classifier gate (profit ≥60%).
